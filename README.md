Build
1. Copy `PixelPerfectLightTheme` directory to `RivaTuner Statistics Server\Skins`
2. Compile with `RTSS.exe -cs PixelPerfectLightTheme`
   - Decompile with `RTSS.exe -ds PixelPerfectLightTheme,jsRfsgTd`
